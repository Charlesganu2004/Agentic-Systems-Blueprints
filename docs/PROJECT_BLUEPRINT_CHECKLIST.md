# Project Blueprint Checklist

Use this checklist before starting a new AI project.

## Define

- Project goal
- Users or workers
- Business value
- Allowed data
- Prohibited data
- Success metrics
- Budget limit
- Review gates

## Choose

- Agent pattern
- RAG storage
- Model provider
- Hosting option
- Evaluation approach
- Logging and monitoring approach

## Build

- Agent roster
- Knowledge node schema
- Source ingestion process
- Retrieval endpoint
- Tool interface
- Prompt policy
- Test set
- Human approval flow

## Verify

- No secrets committed
- RAG returns source-backed results
- Low-confidence answers escalate
- Agents have boundaries
- Costs are tracked
- Customer-facing surfaces are authenticated
- Legal/privacy review is complete for sensitive data
